# Data

The repository includes only the synthetic fixture in `synthetic/`. It does not
redistribute TCGA patient-level data.

Place locally obtained TCGA PanCancer files in `tcga_pancancer_raw/` as described
in the main README. That directory is ignored by Git except for its README.

Users are responsible for obtaining data from the original provider, complying
with its access and use conditions, and preventing patient or sample identifiers
from entering commits, issues, logs, or pull requests.
